# UNO ULTRAS

UNO ULTRAS is a modular web game frontend focused on a playable UNO core loop,
local progression, and an architecture ready for incremental feature expansion.

## Tech Stack

- TypeScript
- Vite
- SCSS

## Install and Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Test

```bash
npm test
```
